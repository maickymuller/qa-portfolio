# Test Plan \- SauceDemo Login Functionality

## Objective

The purpose of this test plan is to validate the login functionality of the SauceDemo application and ensure that users can authenticate successfully according to the expected business rules.

## Scope

The testing scope includes:

- Login with valid credentials
- Login with invalid credentials
- Login with empty fields
- Login validation messages
- Access control after successful authentication

The testing scope does not include:

- Shopping cart functionality
- Checkout process
- Product management

## Test Strategy

The following testing approaches will be applied:

- Functional Testing
- Positive Testing
- Negative Testing
- Exploratory Testing

## Test Environment

- Application: SauceDemo
- URL: [https://www.saucedemo.com](https://www.saucedemo.com)
- Browser: Google Chrome
- Operating System: Windows 11

## Entry Criteria

- Application is accessible.
- Test credentials are available.
- Test environment is operational.

## Exit Criteria

- All planned test cases have been executed.
- Test results have been documented.
- Identified defects have been recorded.

## Risks

- Application availability issues.
- Unexpected changes in the demo environment.
